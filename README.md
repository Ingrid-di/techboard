# Teachboard

Dieses Projekt wurde während meiner Front-End-Studien bei Alura entwickelt.  
Es handelt sich um eine Landing Page, die Echtzeit-Überwachung mit intelligenten Alerts für Webanwendungen zeigt.

## Verwendete Technologien
- HTML5
- CSS3
- Benutzerdefinierte Schriftarten (Unbounded und Poppins)
- Grundlegendes responsives Design

## So kann man es ansehen
1. Klone dieses Repository:
   git clone https://github.com/Ingrid-di/techboard.git
2. Öffne die Datei `index.html` im Browser.

Oder direkt auf GitHub ansehen: [https://github.com/Ingrid-di/techboard](https://github.com/Ingrid-di/techboard)
